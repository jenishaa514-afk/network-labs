
### Days 10 - 12: Multi-Area OSPF & ZBF Security
*   **Goal:** Build a multi-area OSPF network with route summarization and a Zone-Based Firewall.
*   **Accomplished:**
    *   Configured Multi-Area OSPF (Area 0 and Area 1) across 3 routers.
    *   Configured Route Summarization on the ABR (R2).
    *   Implemented a Zone-Based Firewall (ZBF) on R2 to secure the inside network.
    *   Proved the firewall blocked external attacks using a simulated Hacker PC, while allowing internal internet access via NAT Overload.
*   **Challenges:** Learned that Cisco routers bypass their own inbound ACLs/ZBF for self-generated pings. Had to use a separate PC to prove the firewall was working.
